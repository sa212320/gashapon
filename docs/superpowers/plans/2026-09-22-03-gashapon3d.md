## 確認過的 Model(權威來源;實作若與此牴觸,是計畫的 bug —— 停下來反映,不要就地改模型)

### Entities

- `AppPrefs { soundOn }` —— 全域,獨立 storage key
- 每個模式都有 `setups[]` 與 `activeSetupId`
- 扭蛋機 2D:`Prize { id, name, count, rarity }` → `Capsule { prizeId, drawn }`
- 扭蛋機 3D:`Prize { id, name, count, rarity }` → `Capsule { prizeId, drawn, color }`
- 一番賞:`IchibanPrize { id, name, tier(A~G), count }` + `lastOnePrize` → `Ticket { prizeId, drawn }`
- 阿彌陀籤:`Player { id, name, color }` + `GhostPrize { id, name, count }` → `Ladder`(每局現場產生,不存)
- 大亂鬥:`Fighter { id, name, color, count }` + `items{attack,speed,giant,bomb}` → `Combatant { fighterId, alive }`(不存)

### Cardinality

- `Prize` 1:N `Capsule`、`IchibanPrize` 1:N `Ticket`、`GhostPrize` 1:N 底部格子、
  `Fighter` 1:N `Combatant` —— 全部由 `count` 決定,同一個形狀
- `Player` 1:1 梯子上的一條線
- **`Fighter` 就是隊伍**,`count` 就是隊伍人數。同 `fighterId` 的 `Combatant` 不互相擊飛,
  最後還有人活著的 `fighterId` 獲勝

### Seen vs stored

- 3D 看到球體裡五顏六色的蛋 → **顏色是每顆蛋自己隨機挑的**,跟獎項、跟稀有度都無關
- 一番賞看到「A賞 PVC模型」→ 存的是 `tier: 'A'` 欄位,**不是名字前綴**
- 阿彌陀籤看到大家像賽跑有快有慢 → **誰拿到什麼在起跑前梯子就決定好了**,快慢純粹是演出
- 阿彌陀籤底部補的「銘謝惠顧」空籤是**算出來的**,不存進設定
- 大亂鬥是**唯一**結果不預先決定的模式

### 最可能做錯的四個(以下四句都是錯的)

1. 「一番賞的賞別就是稀有度」 —— **一番賞沒有稀有度,扭蛋機沒有賞別**
2. 「大亂鬥的隊伍是一個獨立實體」 —— 沒有 `Team`,隊伍就是同一筆 `Fighter`
3. 「3D 扭蛋機的蛋色由稀有度決定」 —— 只有 2D 那台是。3D 每顆蛋隨機上色
4. 「阿彌陀籤誰先跑到終點誰拿頭獎」 —— 名次跟獎項完全無關

import test from 'node:test';
import assert from 'node:assert/strict';

import { createPrize } from '../gashapon/js/state.js';
import { CAPSULE_COLORS, buildPool3d, createSetup3d, draw3d } from '../gashapon3d/js/model.js';

function seeded(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

test('每顆蛋都有自己的顏色,而且顏色來自蛋殼色盤', () => {
  const prizes = [createPrize({ name: '獎', count: 20, rarity: 'N' })];
  const pool = buildPool3d(prizes, seeded(1));
  assert.equal(pool.length, 20);
  assert.ok(pool.every(c => CAPSULE_COLORS.includes(c.color)));
});

test('蛋的顏色跟稀有度無關 —— 同一個稀有度會出現多種顏色', () => {
  const prizes = [createPrize({ name: '獎', count: 40, rarity: 'UR' })];
  const pool = buildPool3d(prizes, seeded(2));
  assert.ok(new Set(pool.map(c => c.color)).size > 1, 'UR 的蛋應該有多種顏色');
});

test('同一個稀有度與不同稀有度的顏色分佈沒有差別', () => {
  const colorsFor = rarity => new Set(
    buildPool3d([createPrize({ name: '獎', count: 60, rarity })], seeded(5)).map(c => c.color)
  );
  assert.deepEqual([...colorsFor('N')].sort(), [...colorsFor('UR')].sort());
});

test('獎項物件身上沒有 color 欄位', () => {
  const setup = createSetup3d({ prizes: [createPrize({ name: '獎', count: 2, rarity: 'N' })] });
  assert.equal('color' in setup.prizes[0], false, '顏色屬於蛋,不屬於獎項');
});

test('抽獎沿用 2D 的演出腳本:UR 有四次搖、四次升階', () => {
  const setup = createSetup3d({ prizes: [createPrize({ name: '大獎', count: 1, rarity: 'UR' })] });
  const result = draw3d(setup, seeded(3));
  assert.equal(result.revealSteps.filter(s => s.type === 'shake').length, 4);
  assert.equal(result.revealSteps.filter(s => s.type === 'upgrade').length, 4);

test('抽獎不動到 prizes 的 count,也不就地改動 setup', () => {

  const result = draw3d(setup, seeded(4));
  assert.equal(setup.prizes[0].count, 3);
  assert.equal(setup.pool.filter(c => c.drawn).length, 0);
  assert.equal(result.pool.filter(c => c.drawn).length, 1);

  const rng = seeded(6);
  for (let i = 0; i < 2; i++) {
    const r = draw3d(setup, rng);
    assert.ok(r !== null);
    setup = { ...setup, pool: r.pool };

  assert.equal(draw3d(setup, rng), null);

```js
// 立體扭蛋機。規則跟 2D 那台完全一樣,唯一的差別是:
// 每顆蛋自己隨機挑一個殼色,跟獎項與稀有度都無關 —— 所以球體裡看起來五顏六色,
// 但看蛋的顏色完全猜不出抽到什麼。
import { newId } from '../../shared/js/ids.js';
import { expand } from '../../shared/js/roster.js';
import { buildRevealSteps } from '../../gashapon/js/gacha.js';

export const CAPSULE_COLORS = [
  '#FF8D70', '#FFB37A', '#FFD479', '#C9E88A', '#8CF0B4', '#7FD8C9',
  '#8CC9FF', '#A8B8FF', '#C4A2FF', '#F2A5D1', '#FF9DB5', '#FFFFFF',
];

export function buildPool3d(prizes, rng = Math.random) {
  return expand(prizes, prize => ({
    prizeId: prize.id,
    drawn: false,
    color: CAPSULE_COLORS[Math.floor(rng() * CAPSULE_COLORS.length)],
  }));
}

export function createSetup3d({ name = '立體扭蛋機', prizes = [], removeOnDraw = true } = {}) {
  return { id: newId('s3'), name, removeOnDraw, prizes, pool: buildPool3d(prizes) };
}

export function refillSetup3d(setup) {
  return { ...setup, pool: buildPool3d(setup.prizes) };
}

export function remaining3d(setup) {
  return setup.pool.filter(c => !c.drawn).length;
}

export function draw3d(setup, rng = Math.random) {
  const candidates = [];
  setup.pool.forEach((capsule, index) => {
    if (setup.removeOnDraw && capsule.drawn) return;
    candidates.push(index);
  });
  if (candidates.length === 0) return null;

  const index = candidates[Math.floor(rng() * candidates.length)];
  const capsule = setup.pool[index];
  const prize = setup.prizes.find(p => p.id === capsule.prizeId);
  const pool = setup.removeOnDraw
    ? setup.pool.map((c, i) => (i === index ? { ...c, drawn: true } : c))
    : setup.pool;

  return { capsule, prize, pool, revealSteps: buildRevealSteps(prize.rarity, prize) };
}
```

`scene.js` 匯出 `createScene(canvas)` → `{ fill(pool), turn(), eject(capsule), zoomIn(), open(rarity), reset(), dispose() }`。
球體容器用半透明 `MeshPhysicalMaterial`,蛋用 `SphereGeometry` + `InstancedMesh`(數量可能上百)。
蛋在球內的運動用**自寫的簡化碰撞**:球心引力 + 球殼邊界反彈 + 蛋與蛋的距離約束,不引物理引擎。

演出沿用 `revealSteps`:`turn` → `eject` → `zoomIn` → 依 `shake`/`upgrade` 讓蛋在鏡頭前晃動並換發光顏色 →
`crack` 讓蛋殼裂成兩半飛開 → `burst` 粒子 → 結果卡(DOM 疊在 canvas 上)。

## 已知驗不到的範圍

寫進計畫是為了讓執行者不要誤以為自己驗過了:

- **自動化瀏覽器的分頁是背景狀態、rAF 為 0 fps。** 3D 場景與物理模擬的實際觀感在開發過程中**無法驗證**,
  只能驗邏輯與狀態。Task 12 與 Task 15 的「手動確認」必須由人在前景分頁執行。
- **Safari / WebKit 與真實行動裝置沒有任何自動化覆蓋。** 既有的 2D 扭蛋機在 iOS 上就出現過
  「Reduce Motion 導致演出被略過」與「音效沒聲音」兩個只在 iOS 上發生的問題,
  三個新模式同樣有這個風險。
- **物理手感**(撞擊夠不夠爽、節奏會不會拖)只能靠人玩。測試只能保證規則正確,不能保證好玩。
