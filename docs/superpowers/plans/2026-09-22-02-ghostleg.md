### Seen vs stored

- 3D 看到球體裡五顏六色的蛋 → **顏色是每顆蛋自己隨機挑的**,跟獎項、跟稀有度都無關

### 最可能做錯的四個(以下四句都是錯的)

1. 「一番賞的賞別就是稀有度」 —— **一番賞沒有稀有度,扭蛋機沒有賞別**
2. 「大亂鬥的隊伍是一個獨立實體」 —— 沒有 `Team`,隊伍就是同一筆 `Fighter`
3. 「3D 扭蛋機的蛋色由稀有度決定」 —— 只有 2D 那台是。3D 每顆蛋隨機上色
4. 「阿彌陀籤誰先跑到終點誰拿頭獎」 —— 名次跟獎項完全無關

6. 「橫槓越多越公平」 —— **錯**,公平性來自兩端洗牌;橫槓只決定好不好看、跑多久

### Task 1: 梯子演算法

**Files:**
- Create: `ghostleg/js/ladder.js`
- Test: `test/ladder.test.js`

**Interfaces:**
- Consumes: `newId` from `shared/js/ids.js`;`expand`, `countOf` from `shared/js/roster.js`
- Produces:
  - `createPlayer({ name?, color? }): Player`
  - `createGhostPrize({ name?, count? }): GhostPrize`
  - `shuffle(list, rng): T[]` —— Fisher-Yates,回傳新陣列,不改原本的
  - `lineup(players, rng): Player[]` —— 每局把玩家洗到車道上,畫面順序跟設定清單無關
  - `bottomSlots(prizes, playerCount, rng): { prizeId: string|null, name: string }[]` —— 長度**恆等於** `playerCount`;
    展開後**隨機取樣**再洗牌,**不是** `slice(0, playerCount)`
  - `buildLadder({ lanes, rows?, rungs?, rng? }): { lanes, rows, rungs: { row: number, left: number }[] }`
  - `walk(ladder, startLane): number`
  - `assign(ladder, players, slots): { playerId, slotIndex, slot }[]`

`buildLadder` 的 `rungs` 中 `left` 表示這根橫線連接 `left` 與 `left + 1` 兩條直線;
同一 `row` 不得有相鄰的橫線(否則走法會產生歧義)。

```js
import {
  createPlayer, createGhostPrize, bottomSlots, buildLadder, walk, assign,

function seeded(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;

test('沒有橫線時,走下去還是原來那一條', () => {
  const ladder = { lanes: 4, rows: 3, rungs: [] };
  assert.deepEqual([0, 1, 2, 3].map(i => walk(ladder, i)), [0, 1, 2, 3]);
});

test('一根橫線就是把相鄰兩條交換', () => {
  const ladder = { lanes: 4, rows: 3, rungs: [{ row: 1, left: 1 }] };
  assert.deepEqual([0, 1, 2, 3].map(i => walk(ladder, i)), [0, 2, 1, 3]);
});

test('兩根不同列的橫線依序套用', () => {
  const ladder = { lanes: 3, rows: 4, rungs: [{ row: 0, left: 0 }, { row: 2, left: 1 }] };
  // 起點 0:先換到 1,再換到 2
  assert.equal(walk(ladder, 0), 2);
  // 起點 1:先換到 0,之後不再動
  assert.equal(walk(ladder, 1), 0);
  // 起點 2:第一列不動,第三列換到 1
  assert.equal(walk(ladder, 2), 1);
});

  for (let seed = 1; seed <= 40; seed++) {
    const lanes = 2 + (seed % 9);
    const ladder = buildLadder({ lanes, rng: seeded(seed) });
    const ends = Array.from({ length: lanes }, (_, i) => walk(ladder, i));
    assert.equal(new Set(ends).size, lanes, `seed ${seed} 的終點出現重複`);
  }
});

test('buildLadder 不產生同一列相鄰的橫線', () => {
  for (let seed = 1; seed <= 40; seed++) {
    const ladder = buildLadder({ lanes: 6, rng: seeded(seed) });
    const byRow = new Map();
    for (const rung of ladder.rungs) {
      if (!byRow.has(rung.row)) byRow.set(rung.row, []);
      byRow.get(rung.row).push(rung.left);
    }
    for (const [row, lefts] of byRow) {
      const sorted = [...lefts].sort((a, b) => a - b);
      for (let i = 1; i < sorted.length; i++) {
        assert.ok(sorted[i] - sorted[i - 1] >= 2, `第 ${row} 列有相鄰橫線`);
      }
    }

      row.set(r.slot.name, (row.get(r.slot.name) ?? 0) + 1);
```

```js
// 阿彌陀籤(鬼腳圖)。誰拿到什麼由梯子決定,跟跑得快慢完全無關。
import { newId } from '../../shared/js/ids.js';
import { expand } from '../../shared/js/roster.js';

export const EMPTY_SLOT_NAME = '銘謝惠顧';

const PALETTE = [
  '#FF8D70', '#8CC9FF', '#9BE7C4', '#FFD479', '#C4A2FF',
  '#FF9DB5', '#7FD8C9', '#FFB37A', '#A8B8FF', '#F2A5D1',
];

export function createPlayer({ name = '玩家', color = null } = {}) {
  return { id: newId('pl'), name, color: color ?? PALETTE[Math.floor(Math.random() * PALETTE.length)] };
}

export function pickColor(existing) {
  const used = new Set(existing.map(p => p.color));
  return PALETTE.find(c => !used.has(c)) ?? PALETTE[existing.length % PALETTE.length];
}

export function createGhostPrize({ name = '新獎項', count = 1 } = {}) {
  return { id: newId('gp'), name, count: Math.max(0, Math.floor(count)) };
}

// 底部格子數恆等於玩家數:不足補空籤,超過只取前面幾個。
// 補出來的空籤是算的,不存進設定。
export function shuffle(list, rng = Math.random) {
  const out = list.slice();
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [out[i], out[j]] = [out[j], out[i]];
  }
  return out;
}

export function lineup(players, rng = Math.random) {
  return shuffle(players, rng);
}

// 展開 → 洗牌 → 取前 playerCount 個。
// 不能用 slice(0, playerCount) 取原順序:獎項比人多的時候,排在清單後面的獎項會永遠
// 抽不到,而畫面上不會有任何提示。先洗再取,每個獎項每局都有機會上場,
// 數量多的獎項自然比較常被選中(它展開後佔比較多份)。
export function bottomSlots(prizes, playerCount, rng = Math.random) {
  const filled = shuffle(expand(prizes, p => ({ prizeId: p.id, name: p.name })), rng);
  const slots = filled.slice(0, playerCount);
  while (slots.length < playerCount) slots.push({ prizeId: null, name: EMPTY_SLOT_NAME });
  return shuffle(slots, rng);
}

// rows 決定「跑道多長 / 看多久」,density 決定「看起來多亂」。
// 這兩件事以前綁在 rows = lanes * 2 上,結果 40 人時跑道變成 80 列、跑一次很久。
// 公平性不在這裡 —— 它來自 lineup 與 bottomSlots 兩端的洗牌,
// 所以 rows 可以純粹照「一次看得完多久」來定。
export function buildLadder({
  lanes,
  rows = Math.min(16, Math.max(12, lanes)),
  density = 0.45,
  rng = Math.random,
}) {
  const rungs = [];
  for (let row = 0; row < rows; row++) {
    let left = 0;
    while (left < lanes - 1) {
      if (rng() < density) {
        rungs.push({ row, left });
        left += 2;   // 跳過一條,避免同一列出現相鄰橫線(會讓走法產生歧義)
      } else {
        left += 1;
      }
    }
  }
  return { lanes, rows, rungs };
}

export function walk(ladder, startLane) {
  let lane = startLane;
  for (let row = 0; row < ladder.rows; row++) {
    const here = ladder.rungs.find(r => r.row === row && (r.left === lane || r.left + 1 === lane));
    if (!here) continue;
    lane = here.left === lane ? lane + 1 : lane - 1;
  }
  return lane;
}

export function assign(ladder, players, slots) {
  return players.map((player, lane) => {
    const slotIndex = walk(ladder, lane);
    return { playerId: player.id, slotIndex, slot: slots[slotIndex] };
  });
}
```

```js
// 把 walk 的過程展開成逐列的座標,給動畫沿著畫。
// 這支不決定任何結果 —— 它的終點必定等於 walk。
export function pathOf(ladder, startLane) {
  const path = [{ row: -1, lane: startLane }];
  let lane = startLane;
  for (let row = 0; row < ladder.rows; row++) {
    const here = ladder.rungs.find(r => r.row === row && (r.left === lane || r.left + 1 === lane));
    if (here) {
      lane = here.left === lane ? lane + 1 : lane - 1;
      path.push({ row, lane });
    }
  }
  path.push({ row: ladder.rows, lane });
  return path;
}
```

## 3D 演出層的規格(Task 2 用)

這一節是 grill 之後新增的,`track.js` 與 `camera-script.js` 照這裡做。

**鏡頭腳本**,四段,總長固定約 10 秒,**不做快轉鍵**:

| 段 | 長度 | 鏡頭 | 目的 |
|---|---|---|---|
| 掃視 | 1.5s | 俯視,整條梯子入鏡 | 讓小孩看清楚線是怎麼連的 |
| 就位 | 0.8s | 降到起跑線後方 | 轉場 |
| 跑 | ~6s | 跟著**跑最前面那群**沿跑道前進 | 速度感 |
| 收尾 | ~1.5s | 退開到全部入鏡 | 落後的人也要被看到抵達 |

**落後的人會跑出畫面**,這是 (C) 跟拍的已知代價。收尾段的退開就是補這件事 ——
所有人的抵達必須是集體的,不能有人在鏡頭外默默結束。

**版面隨人數變**(上限 40):
- `lanes <= 8`:車道寬度固定,鏡頭不動
- `lanes > 8`:開始壓縮車道寬度,鏡頭只退一點點
- 角色頭上的名字一律朝向鏡頭(billboard)

**軌跡帶**:每個角色在地面留下自己顏色的帶子,在橫槓處直角轉彎,**跑完不消失**。
結尾退開時看得到「起點 → 一路轉彎 → 我的獎」的完整圖。

**顏色**:20 色調色盤,`pickColor` 自動指派、用完才重複。
**名字才是識別** —— 不要寫出任何「靠顏色分辨誰是誰」的邏輯或文案。

**結果清單**:抵達後疊一張可捲動的清單(誰 → 什麼獎)。40 個人的結果不可能在一個
畫面上讀完,而且老師需要把它抄下來。

## 已知驗不到的範圍

寫進計畫是為了讓執行者不要誤以為自己驗過了:

- **自動化瀏覽器的分頁是背景狀態、rAF 為 0 fps。** 3D 場景與物理模擬的實際觀感在開發過程中**無法驗證**,
  只能驗邏輯與狀態。`gashapon3d` 計畫 Task 2 與 `smash` 計畫 Task 3 的「手動確認」必須由人在前景分頁執行。
- **Safari / WebKit 與真實行動裝置沒有任何自動化覆蓋。** 既有的 2D 扭蛋機在 iOS 上就出現過
  「Reduce Motion 導致演出被略過」與「音效沒聲音」兩個只在 iOS 上發生的問題,
  三個新模式同樣有這個風險。
- **物理手感**(撞擊夠不夠爽、節奏會不會拖)只能靠人玩。測試只能保證規則正確,不能保證好玩。
