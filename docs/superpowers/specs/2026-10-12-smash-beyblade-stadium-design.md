# 大亂鬥:戰鬥陀螺對戰盤(issue #4)— 設計

日期:2026-10-12 · 分支:`smash-beyblade`

全部決定來自 2026-10-12 的 grill 與 brainstorming(使用者逐題拍板),**不要再重問**。
實作時發現跟下面的模型矛盾 = **計畫寫錯了**,停下來提出,不要就地改模型。

## 確認過的模型(原文,不要改寫)

grill 結束時確認,brainstorming 第 3 段經使用者同意修正過道具(拿掉 giant、加 shield、劍盾改成時效疊加),以下是修正後的版本。

- **Setup**(存檔):`items` 開關 = `{ attack, shield, spin, missile }`。舊存檔 `speed` → `spin`、`bomb` → `missile`;`shield` 預設開;`giant` 丟掉。存檔 schema 版本不升。
- **Fighter** = 隊伍 `{ id, name, color, count }`,**不改**,沒有動物欄位。
- **Combatant**(只在比賽中):開打時隨機 `animal`(10 選 1)與 `beyType`(`attack | defense | stamina`),**兩者各自獨立、完全隨機**;另有 `spin`(0..1,轉速 = 命)、`outBy`(`ringout | spinout | burst`)、`buffs: { attack: [剩餘秒數…], shield: [剩餘秒數…] }`。
- **Stadium**:一份常數 + 純函式,**物理與畫面共用** —— 圓角方形、外牆整圈封閉、3 個口袋集中在靠鏡頭那一側(兩角落小、中間大)、加速軌道沿外牆繞整圈(口袋處斷開)。
- **MissileStrike**(只在比賽中):`{ id, fighterId(發射隊伍), x, y(準星), fuse }`。
- **數量**:Setup 1:N Fighter;Fighter 1:N Combatant(= count);Combatant 1:1 animal、1:1 beyType。
- **看到 vs 存下**:動物與陀螺類型看得到但**從不存檔**、每場重抽;存檔只有隊名 / 色 / 人數 / 道具開關。只靠隊伍色分隊。
- **最可能做錯的(錯誤版本,看到就要警覺)**:
  - ❌「動物是隊伍的屬性 `Fighter.animal`」—— 動物屬於每一顆陀螺,每場隨機,不存檔
  - ❌「陀螺造型是純裝飾,或跟著動物走」—— 造型 = 類型、有強弱,跟動物各自獨立
  - ❌「飛彈追蹤敵人、只炸敵隊」—— 鎖定最近敵人**當下的位置**從天空落下、不追蹤;圈內敵我都炸
  - ❌「盤子模型與物理的牆 / 口袋 / 坡度各自定義」—— 兩邊都從 `stadium.js` 來

## 第 1 段:對戰盤(`stadium.js`)

- **參考真實的盤子**:形狀、口袋、軌道的比例要對照真的 Beyblade X Xtreme Stadium(Takara Tomy)。做盤子畫面前先收集真盤子的俯視 / 斜視參考圖,跟預覽頁並排比對;使用者手邊有照片的話以那張為準。網路上現成的 3D 模型(例如 Printables 的粉絲版 Xtreme 盤)**只當量比例的參考**(口袋寬深、坡度、軌道高度、圓角),數字填進 `stadium.js`、用我們的畫風重畫;**不載入、不散布別人的模型檔**(物理會對不上、畫風不合、授權與 Takara Tomy 智財風險)。
- **形狀**:圓角方形,半寬 `HALF = 100`、圓角半徑 `CORNER = 30`;**外牆繞整圈、完全封閉**。
- **出口 = 口袋**(2026-10-12 使用者看真盤子後修正):不是牆上的缺口,而是外牆內側凹下去的 3 個口袋,都在**靠鏡頭那一側**(物理 +y = 畫面 +z):兩個角落各一個小口袋(寬約 24)、中間一個大口袋(寬約 38),比例照真的盤子(Over Zone 12cm / Xtreme Zone 19cm)。陀螺**中心越過口袋邊緣線且落在口袋範圍內** → `outBy: 'ringout'`,掉進口袋、**停在裡面**(不消失、不掉出畫面),口袋裡愈堆愈多。
- **牆**:碰牆就反彈,反彈係數約 0.7,並小幅扣轉速;**不**產生撞擊火花 / 音效(不然畫面一直閃)。
- **坡度**:中央約 35% 是平的,往外愈來愈陡,推力朝內;用「離牆多遠」(圓角方形的距離場)計算,角落也會往中間推。`heightAt(x, y)` 跟推力用**同一條曲線**,畫面與陀螺站的高度都用它。
- **加速軌道**:沿外牆內側**繞整圈**、寬約 10 的帶狀區域,**碰到口袋就斷開**。陀螺在帶內時,順著它原本沿牆移動的方向加速,有速度上限;**離開軌道時加一個朝中央的分量,衝向戰場中央**(不是衝向口袋)。被撞進口袋仍然會發生,但不是軌道造成的。
- **鏡頭**:俯角從約 33° 拉高到約 50°,讓前牆不擋住口袋內部;預覽頁 45° / 50° / 55° 並排截圖給使用者挑。
- **測試**:口袋範圍內越線的點出局、其他牆邊的點反彈;坡度推力永遠朝內;`heightAt` 中央最低、往外遞增;軌道推力沿牆的切線方向。

## 第 2 段:陀螺(`beys.js`、`bey3d.js`)

- **轉速 `spin`**:從 1 開始,每秒自然掉約 1/30(單獨一顆約轉 30 秒),被撞時依撞擊力道再扣;歸 0 → `outBy: 'spinout'`。保險時間上限 `MAX_TIME` 45 → 60 秒。
- **類型數值**(起始值,實測再調):

  | 類型 | 撞人力道 | 重量 | 轉速衰減 | 爆裂 |
  |---|---|---|---|---|
  | 攻擊(attack) | ×1.4 | 1 | ×1.5 | 撞別人時對方爆裂機率 ×1.5 |
  | 防禦(defense) | ×0.8 | 1.8 | ×1 | 自己被爆機率 ×0.5 |
  | 耐久(stamina) | ×1 | 0.8 | ×0.6 | 普通 |

- **爆裂**:受到 ≥ `HIT_POWER` 的重擊時擲骰。基準 = 最重一擊(`HIT_FULL`)約 25%,依力道線性;再乘攻擊方 / 防禦方的類型係數、劍盾層數;**轉速愈低愈容易爆**(轉速 0 時最多 ×2)。這只影響爆裂,不影響撞擊力。命中 → `outBy: 'burst'`。
- **人多**:總人數 > 20 時半徑 = `8 × √(20 / 人數)`。
- **造型**(參考 Beyblade X 的三件式,取輪廓特徵、不照抄任何一款):
  - 戰刃(Blade,最上、最大塊,**隊伍色**):攻擊型 = 3 片往前勾的大彎刃;防禦型 = 一圈幾乎連續的圓盾牆、只有淺凸起;耐久型 = 寬大偏圓的薄盤、外緣細翅片
  - 固鎖(Ratchet,中間有凸齒的環,隊伍色深一階)
  - 軸心(Bit,金屬灰軸尖,底部一圈齒輪 —— 加速軌道咬的就是它)
  - 頂上**朝上、不跟著轉**的動物圓片:爬格子那 10 張圖(`ghostleg/img/animals/*.webp`,沿用帶 `?v=` 的網址),畫布裁成圓形當貼圖,每種只做一次;有描邊
  - 先做預覽頁三種並排,390 / 1440 截圖給使用者挑,定案後再接進遊戲
- **演出**:
  - 轉速低:轉得變慢 + 進動搖晃,低於 35% 明顯;不顯示血條
  - 停轉:慢慢傾倒、躺平約 1 秒後淡出(物理上一倒就移除,不擋路)
  - 爆裂:戰刃(連同動物圓片)、固鎖、軸心三件往三個方向噴開,有重力與翻轉 + 撞擊星 + `sfx.burst`
- **測試**:分配出來的類型帶正確數值;轉速歸 0 出局且 `outBy` 正確;固定種子下爆裂機率在預期範圍;**每一場都會結束**(跑完整場的測試改成:沒有道具時也一定在 `MAX_TIME` 內分出勝負或平手)。

## 第 3 段:道具、飛彈、行為、開場

- **道具**:`ITEM_TYPES = ['attack', 'shield', 'spin', 'missile']`,每 2.6 秒在盤面隨機位置掉一個(不掉在口袋上)。
  - **劍 / 盾:每吃一個多一層**,每層各自倒數 **8 秒**,最多 **3 層**(滿了再吃 → 刷新最舊那層)。
    - 劍,每層:撞別人時對方彈開力道 ×1.9(沿用現行 `ATTACK_GAIN`)、對方爆裂機率 ×1.5
    - 盾,每層:自己被撞的彈開距離 ×0.6、自己被爆機率 ×0.5
  - **補包**:轉速立刻補滿。
  - **飛彈**:見下。
  - 提示:劍 = 外框變紅、層數愈多愈粗;盾 = 陀螺周圍冰藍半透明護罩環、層數愈多愈不透明;補包 = 外框閃綠約 0.6 秒。
- **飛彈**(取代炸彈;`spawnBomb` / `explodeBombs` / 炸彈畫法整套換掉):
  - 吃到的瞬間鎖定**最近敵人當下的座標**,建立 `MissileStrike`(倒數 1.2 秒);場上沒有敵人就什麼都不發生。
  - 地上:**發射隊伍色**的準星圈,邊倒數邊縮、閃;圈的大小 = 爆炸範圍(半徑 46)。
  - 天上:程式畫的卡通飛彈(彈頭 / 彈身 / 尾翼),從左上方斜落到準星。
  - 爆炸:沿用現在的星形爆炸 + 衝擊波,推力 620 ÷ 重量,**圈內不分敵我**;每顆被炸到的都擲爆裂骰。
- **行為**(`think()`):找人力道 90 → 約 45;拿掉躲邊緣;撿道具拉力 110 → 約 60;準星倒數剩 0.8 秒時圈內的往外偏,力道約 80;原本速度道具加快找人的那段拿掉。
- **開場**:按開始 → 中央大字「3」「2」「1」「Go Shoot!」各約 0.5 秒;倒數時物理不跑、陀螺停在上方;「Go Shoot!」時陀螺落到起始點(`sfx.drop`)後開打;點一下畫面直接跳到開打;每個數字配現有短音效(`sfx.clunk` 或小聲 `sfx.hit`),不加新音效檔。
- **存檔與設定**:`sanitize` 依模型做遷移;道具分頁改成「⚔️ 攻擊」「🛡️ 防護」「🩹 回轉」「🚀 飛彈」並改說明文字(設定裡維持表情符號,生成圖只用在場上)。
- **鏡頭**:拿掉變大以後不用替身體變大留空間,`frameCamera` 簡化成固定取景(仍依長寬比算距離,讓盤子在手機與桌機都完整入鏡)。
- **測試**:舊存檔 `speed` / `bomb` / `giant` 遷移正確、`shield` 預設開;飛彈鎖定的是發射當下的位置(目標之後移開也不追);圈內隊友也被炸;補包把轉速補回 1;劍盾每層到時間消失、最多 3 層。

## 第 4 段:畫面、素材、施工順序

- **盤子畫面**(`stadium3d.js`):盤底是一張網格,每個頂點的高度用 `stadium.heightAt` 算;平塗看不出凹凸,所以加「中間淺、外圍深一點」的頂點色漸層 + 3 圈沿坡度的等高線。外牆 = 擠出的冰藍塑膠、整圈封閉;口袋 = 外牆內側的凹槽,內側深色,出局的陀螺躺在裡面;軌道 = 白色齒沿外牆排一圈、口袋處斷開。沿用現有「每個零件自己一層描邊殼」的做法。
- **陀螺畫面**:見第 2 段;陀螺的高度跟著 `heightAt` 走。
- **飛彈、準星**:程式畫,不用圖。
- **道具圖**(劍、盾、補包、飛彈):`tools/mascot-gen` 生成,吉祥物畫風(平塗、粗深棕外框、Q 版)、**彩色**;先試 4 格拼圖再切,不行就分開生成、每張 3 版。候選圖合成到實際盤面上截圖給使用者挑。定案後轉 webp、網址帶內容雜湊、加進首頁 `preload.json` 與頁內預先載入。場上是正對鏡頭、上下浮動、有地上影子的圖示(不再是球)。
- **驗證**:對戰盤與陀螺各先做預覽頁,390(iframe 包住截圖)與 1440 兩種寬度截圖;最後在真的頁面用 claude-in-chrome 錄一場完整比賽(錄之前確認 `document.visibilityState`,背景分頁 rAF 不跑)。
- **施工順序**(每步可單獨測、單獨 commit):
  1. `stadium.js` + 物理接牆 / 口袋 / 坡度 / 軌道,拿掉 `shrink`
  2. `beys.js`:類型、轉速、停轉、爆裂;整場會結束的測試要過
  3. 道具改版:劍盾時效疊加、補包、飛彈取代炸彈、存檔遷移、設定分頁
  4. 收集真盤子參考圖 → 對戰盤畫面 → 預覽頁(含鏡頭 45° / 50° / 55°)→ 使用者確認
  5. 陀螺三種造型 + 動物圓片 → 預覽頁 → 使用者挑;接上停轉 / 爆裂演出
  6. 道具圖生成 → 使用者挑
  7. 開場「3、2、1,Go Shoot!」
  8. 真頁面驗證 → 首頁卡片插畫(截圖 + Qwen edit)
